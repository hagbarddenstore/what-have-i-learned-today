## Mapping the running user to Podman root

I've learned how to map the running users id to the `root` user inside the
container. This allows the container to create files inside it that are mapped
as a volume to have the correct permissions on the outside.

I ran the command `podman run -d -v ./:/home/test --rm ubi9 /bin/bash -c 'touch /home/kim/test'`
on my host as the user `kim`.

`ls /home/kim` inside the container looks something like this:

```
drwx------ 7 root root 4096 Nov 16 09:36 .
drwxr-xr-x 1 root root 4096 Nov 16 09:36 ..
-rw-r--r-- 1 root root    0 Nov 16 09:36 test
```

And outside it looks like this:

```
drwx------ 7 kim  users 4096 Nov 16 09:36 .
drwxr-xr-x 3 root root  4096 Oct 29 13:59 ..
-rw-r--r-- 1 kim  users    0 Nov 16 09:36 test
```

By default podman maps the current users id to the first user inside the container,
which is the `root` user.

Source: https://www.redhat.com/en/blog/rootless-podman-user-namespace-modes
