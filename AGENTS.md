# Daily learning notes

- Keep a collection of Markdown files with one file per day, summarizing things learned throughout that day.
- Name each file with the current date in `YYYY-MM-DD.md` format, and use that date as the file's top-level title (`# YYYY-MM-DD`).
- Give every learning entry in the file its own title and text.
- Add all entries from the same day to that day's existing file rather than creating another file.
